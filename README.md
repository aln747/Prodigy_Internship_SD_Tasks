# Prodigy InfoTech Software Development Internship

This repository contains the projects and tasks completed during my **one-month Software Development Internship at Prodigy InfoTech**.

## Internship Details

* **Organization:** Prodigy InfoTech
* **Domain:** Software Development
* **Duration:** 15 August 2026 – 15 September 2026
* **Language:** C++

## Tasks

### Task 01 — Temperature Converter

A C++ program to convert temperatures between **Celsius, Fahrenheit, and Kelvin**.

### Task 02 — Number Guessing Game

A random number guessing game that provides **too high/too low** feedback and tracks the number of attempts.

### Task 03 — Contact Management System

A program to **add, view, edit, and delete contacts**, with contact information stored for management.

### Task 04 — Sudoku Solver

A program that automatically solves **Sudoku puzzles using backtracking** and displays the completed grid.

### Task 05 — Product Information Scraper

A program that extracts **product names, prices, and ratings** from an e-commerce website and stores the data in **CSV format**.
